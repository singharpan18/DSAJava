7.Recusion & backtacking
Easy Rule
ArrayList, StringBuilder, arrays → modify same object → backtracking needed.
String, Integer, Boolean → immutable → backtracking not needed.

In Combination Sum, after picking an element:
combinationSum(arr, index, target - arr[index], current, result);
we stay at the same index because reuse is allowed.
If reuse is NOT allowed, then after picking we must move forward:
combinationSum(arr, index + 1, target - arr[index], current, result);
because that element cannot be used again.
